To get the local server running again, open Terminal and:

cd "/Users/johnbrooks/Documents/Personal Documents/Essex Pathway/Pathway Portal/portal"
python3 -m http.server 8000

Then in your browser: 


http://localhost:8000


The quotes around the path are needed because of the spaces in "Personal Documents" and "Essex Pathway" and "Pathway Portal". Without them, the cd command will fail.
Leave Terminal running while you work — closing it stops the server. To stop the server intentionally, press Ctrl+C in the Terminal window.
